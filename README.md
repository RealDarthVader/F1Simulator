# F1 Legends Simulator

A Formula 1 championship simulator featuring legendary and modern drivers competing in equal machinery.

## Live Demo

https://f1-simulator-red.vercel.app/

## Features

- Driver ratings system
- Qualifying simulation
- Race simulation
- Weather effects
- Track modifiers
- Championship standings
- Interactive dashboard

## Tech Stack

- Python
- HTML
- CSS
- JavaScript
- Chart.js
- Vercel

## Run Locally
Clone the repository:

```bash
git clone https://github.com/RealDarthVader/F1Simulator.git
cd F1Simulator
```

Run the Python simulator:

```bash
python f1sim.py
```

Or open `index.html` in your browser.
